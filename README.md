# 📦 Inventory Management API
### Module 2: FastAPI & Data Filtering

This project is a high-performance Inventory API built with **FastAPI**. It allows for dynamic product searches and price-range filtering, designed with clean logic and scalability in mind.

## 🚀 Features
* **Product Search:** Filter by name and price with case-insensitive logic.
* **Price Range Finder:** Query products within a specific minimum and maximum price.
* **Auto-Documentation:** Interactive Swagger UI built-in.

## 🛠️ Setup & Tech Stack
* **Language:** Python 3.x
* **Framework:** FastAPI / Uvicorn
* **Environment:** Linux (PyCharm)

```bash
# How to run locally
pip install -r requirements.txt
uvicorn main:app --reload
```

🧪 Testing the API
Once the server is running, visit the interactive docs at:
http://127.0.0.1:8000/docs
